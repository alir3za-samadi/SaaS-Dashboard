# داشبورد مدیریت SaaS

> یک داشبورد مدیریت مدرن و واکنشی (Responsive) که با **React**، **TypeScript** و **Tailwind CSS** ساخته شده است. این پروژه دارای کامپوننت‌های جدول عمومی (Generic Table)، پشتیبانی از حالت تاریک/روشن و مدال‌های تمرینی کاربردی است.

**🔗 پیش‌نمایش زنده:** [SaaS Dashboard](https://saas-dashboard.freedev.app/)


## ویژگی‌ها

* 📊 **تحلیل و نمای کلی** - نمایش بصری معیارهای کلیدی، آمارها و فعالیت‌های کاربران
* 🗂️ **جدول عمومی و تایپ‌سیف (Reusable Generic Table)** - کامپوننت پویا `<Table<T>>` توسعه‌یافته با تایپ‌اسکریپت برای رندر مطمئن داده‌ها
* 🌓 **سوئیچ تم تاریک / روشن** - مدیریت کامل تم از طریق React Context API با ذخیره‌سازی ترجیحات کاربر
* 🪟 **مدال‌های تعاملی** - دیالوگ‌های مدال کاربردی و استاندارد برای تجربه کاربری بهتر
* 📱 **طراحی کاملاً واکنش‌گرا** - رابط کاربری بهینه‌شده برای موبایل و دسکتاپ با Tailwind CSS
* ⚡ **سرعت بالا** - قدرت‌گرفته از Vite برای HMR آنی و خروجی نهایی سبک

## تکنولوژی‌های استفاده‌شده

| بخش | ابزار / کتابخانه |
| --- | --- |
| فریم‌ورک / کتابخانه | [React](https://react.dev/) |
| ابزار باندلر | [Vite](https://vitejs.dev/) |
| زبان | [TypeScript](https://www.typescriptlang.org/) |
| استایل‌دهی | [Tailwind CSS](https://tailwindcss.com) |

## ساختار پروژه

```text
src/
├── assets/          # فایل‌های استاتیک، لوگوها و تصاویر
├── components/      # کامپوننت‌های UI مشترک (دکمه، مدال، کارت، نوار navigation)
│   └── ui/          # پایه‌ای‌ترین کامپوننت‌ها و جدول عمومی Table<T>
├── context/         # ارائه‌دهنده‌های پرووایدر (ThemeContext و AppContext)
├── hooks/           # هوک‌های اختصاصی رکت (Custom Hooks)
├── types/           # تایپ‌ها و اینترفیس‌های ژنریک TypeScript
└── views/           # صفحات اصلی (داشبورد، آنالیتیکس، تنظیمات، کاربران)

```

## دلیل انتخاب این معماری

### کامپوننت جدول عمومی و تایپ‌سیف (`Table<T>`)

به جای نوشتن جداول تکراری برای هر صفحه، پروژه از یک جدول ژنریک و تایپ‌سیف `<Table<T>>` استفاده می‌کند. این کار امنیت تایپ‌اسکریپت را در ستون‌ها و رندر داده‌ها تضمین کرده و از کدهای تکراری جلوگیری می‌کند.

### مدیریت تم با Context API

وضعیت تم‌های تاریک و روشن توسط `ThemeContext` مدیریت می‌شود. این بخش با `classList` سند HTML و `localStorage` مرورگر همگام است تا از پرش تم (Flicker) هنگام رفرش جلوگیری کرده و نیازی به کتابخانه‌های سنگین مدیریت وضعیت نداشته باشد.

### مسیریابی SPA در InfinityFree

از آنجا که سرورهای InfinityFree استاتیک (Apache) هستند، یک فایل `.htaccess` سفارشی درون پوشه `public/` قرار داده شده تا تمامی درخواست‌های مسیر به `index.html` هدایت شوند و مسیریابی سمت کلاینت (Client-side routing) هنگام رفرش صفحه با خطای ۴۰۴ مواجه نشود.

## راه اندازی پروژه

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/alir3za-samadi/SaaS-Dashboard.git
cd SaaS-Dashboard

# ۲. نصب وابستگی‌ها
pnpm install

# ۳. اجرای سرور توسعه
pnpm dev

# ۴. ساخت نسخه نهایی برای دپلوی (InfinityFree)
pnpm build

```

پس از ساخت نسخه نهایی، محتویات پوشه `dist/` را درون پوشه `htdocs` در هاست InfinityFree خود آپلود کنید.

سپس آدرس [http://localhost:5173](http://localhost:5173) را در مرورگر باز کنید.
